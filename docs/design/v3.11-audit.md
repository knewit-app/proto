# v3.11 디자인 점검 (Impeccable critique · audit)

- 기준: 레포 루트 `DESIGN.md`(iOS 27 · Liquid Glass), Impeccable 4.8.0 `critique` · `audit` · `reference/ios.md`
- 대상: `v/3.10.1.html`의 폰 프레임 안쪽. 기준 기기 iPhone SE 375×667, 기본 글자 · 큰 글자(×1.18)
- 대표 화면: S-ONB-01 · 03 · 04, S-HOME-01(추천 · 지도), S-HOME-04, S-PLC-01, S-PLS-01, S-MY-01, S-MY-05, 시트 S-PLC-01a · S-ONB-03a

- 화면 사진: `docs/design/shots/`
