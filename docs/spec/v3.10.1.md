- 0: 프로토타입 버그. 명세는 그대로이고 화면을 명세에 맞췄다.
- 1: 화면에서 보이는 변경. 프로토타입과 기능명세서를 같이 고친다.
- 2: 공통 규칙(COM) 신규 행.
- 3: 법무 검토.

## 1. 프로토타입 + 기능명세서

| 행 ID | 바꿀 내용 |

| FN-ON-040 | **카드사 선택은 로고 타일이다.** 지원 카드사와 준비 중 카드사를 모두 한 화면에 보인다. '준비 중인 카드사' 링크와 펼침 상태는 없앤다.<br>- 지원 카드사(6곳): 2열 큰 타일. 위에 로고를 가로로 넓게(로고 영역 높이 24px, 왼쪽 정렬), 아래에 '최근 N개월'. 타일 높이는 64~72px이다.<br>- 준비 중 카드사(8곳): '준비 중' 소제목 아래 4열 작은 타일. 로고는 흑백 · 흐리게(opacity .45), 이름은 로고 아래 작은 글자다.<br>- 각주는 '본인 명의 개인카드만' 한 줄이다. 부제 '한 번 로그인하면 그 카드사의 카드가 모두 연결돼요'는 유지한다.<br>- 로고는 각 카드사 공식 CI 파일을 원본 그대로 쓴다. 파일을 구하지 못한 카드사는 이름 텍스트로 둔다.<br>- 한 화면 기준(v3.9.2): 기준 기기(iPhone SE 375×667) 기본 글자에서 14곳과 하단 버튼이 스크롤 없이 보인다. 큰 글자에서는 스크롤을 허용한다. 제목은 강제 줄바꿈 없이 한 줄('어느 카드사를 연결할까요')로 두고, 좁으면 자연스럽게 줄바꿈한다. |
| FN-ON-090 | 준비 중 카드사 타일을 누르면 확인 시트를 띄운다: '○○카드가 지원되면 알려 드릴게요' + '알림 받기'.<br>신청한 카드사 타일에는 '알림 신청함'을 표시하고, 다시 누르면 '이미 신청했어요' 토스트만 띄운다.<br>알림을 처음 쓰는 자리이므로, iOS 알림 권한이 아직 안 물음이면 신청 직후 iOS 알림 팝업을 띄운다(FN-ON-031). |

## 2. 공통 규칙

| 행 ID | 내용 |
| --- | --- |
| COM-21 (신규) | **하단 버튼**<br>한 단계를 끝내거나 다음으로 넘기는 주 버튼은 공통 하단 버튼 영역에 둔다.<br>- 화면은 세로 flex · 높이 100%. 버튼 영역은 `margin-top:auto` + `position:sticky; bottom:0`이라, 내용이 짧아도 화면 아래에 붙는다.<br>- 내용이 길면 내용만 스크롤되고 버튼 영역은 화면 아래에 남는다. 버튼 영역 위쪽은 흰색 그라데이션으로 내용과 나눈다.<br>- 마지막 버튼의 아래 여백은 홈 인디케이터를 포함해 모든 화면에서 같다(±2px, 프로토타입 `--bot-gap` 30px).<br>- 전체 화면 시트(세부 조건 S-HOME-02, 새 목록 S-PLS-02)도 같은 영역을 시트 아래에 둔다.<br>적용 화면: S-INV-01, S-ONB-01, S-ONB-02, S-ONB-03, S-ONB-04, S-ONB-05, S-ONB-06, S-PRF-01, S-CMN-01, S-HOME-02, S-PLS-02.<br>예외: 내용 안의 행동 버튼은 그대로 둔다 — 장소 상세의 길찾기 · 카톡으로 같이 가자, 프로필의 공유 · 친구 추가, 친구 프로필 버튼, 친구 추가의 공유 버튼. |

S-CMN-01(빈 상태 · 오류)은 전체 화면 상태로 보고 탭바 없이 띄운다. 탭바 위에 버튼이 뜨면 아래 여백이 다른 화면과 달라지기 때문이다. 돌아갈 곳이 있는 상태는 뒤로 버튼으로 돌아간다.

## 로고

파일로 내려받지 않고, 각 카드사 공식 CI 페이지가 쓰는 이미지 주소를 그대로 링크한다. 주소와 확인 날짜는 `assets/issuers/SOURCES.md`에 적는다. 이미지를 불러오지 못하면 카드사 이름 텍스트로 대신 보인다.

- 로고로 보이는 곳(2): 신한카드, 제주카드(제주은행 시그니처).
- 이름 텍스트로 두는 곳(12)
  - 공식 이미지는 있지만 여러 조합 · 라벨 · 격자 · 치수가 함께 있는 안내 이미지: KB국민카드, 하나카드, 우리카드, 광주카드, 전북카드, 롯데카드, 현대카드
  - 공식 PNG/SVG 없음: 삼성카드, BC카드(GIF · AI만), NH농협카드, 씨티카드, 수협카드
- 단독 로고 파일은 카드사 홍보팀에 요청해 받는 것이 맞다(L-13과 함께 확인).
