# 기능명세서 v3.8 변경분

v3.7을 BE 관점에서 검토한 결과를 반영한다. 프로토타입은 `v/3.8.html`.

- A: 화면에서 보이는 문제. 프로토타입과 기능명세서를 같이 고친다.
- B: 서버 설계에만 해당하는 문제. 기능명세서에만 반영한다.

## 0. 기본안 (팀 확정 전)

프로토타입은 이 값들을 `POLICY` 상수 한곳에 모아 두었다.

| 기준 | 내용 | 기재할 행 |
| --- | --- | --- |
| K1 가게 판정 규칙의 키 | **카드사별 가맹점번호**<br>방문 확인에서 고르면 그 결제의 가맹점에 적용하고, 장소 상세에서 고르면 그 장소에 연결된 내 가맹점 전부에 적용한다.<br>간편결제 · PG 가맹점은 '다른 장소였어요' 자동 매핑을 하지 않고 매번 묻는다. | FN-FR-080 · FN-SY-081 · FN-PL-040 |
| K2 고치기 단위 | **방문 1건**(30분 병합 단위). 장소 전체가 아니다. | FN-PL-040 |
| K3 횟수 기간 | 3회 · 10회(단골) 판정과 내 장소 핀 숫자는 모두 **최근 6개월**. 전체 이력은 장소 상세에서만 보여 준다. | FN-FR-080 |

세 행 모두 비고에 "기본안, 팀 확정 전"을 적는다.

## A. 프로토타입 + 기능명세서

| 행 ID | 바꿀 내용 |
| --- | --- |
| FN-PL-040 | 장소 상세의 방문 목록 **각 행**에서 '기록이 틀렸나요?'로 진입한다.<br>**다른 장소였어요**: 그 1건만 고른 장소로 옮긴다. 원래 장소는 -1, 새 장소는 +1. 같은 가맹점의 다음 결제에도 적용한다(K1).<br>**여기 간 적 없어요**: 그 1건만 빼고 범위 선택 시트(S-HOME-04b)로 간다.<br>남은 방문이 0건이면 그 장소의 내 방문 기록 영역은 '아직 안 가본 곳이에요'가 된다.<br>장소 상세에서 만든 규칙은 그 장소에 연결된 내 가맹점 전부에 적용하고, 간편결제 결제는 빠진다. |
| COM-16 | 토스트의 되돌리기는 **방문 복구와 함께 그 동작이 만든 가게 판정 규칙을 삭제**한다. 대상은 '앞으로도 빼기'와 '다른 장소였어요'. |
| FN-SE-010 | 카드사 연결 해제 시 **그 카드사 결제에서 만든 가게 판정 규칙도 삭제**한다. '다시 묻지 않는 가게' 목록에서도 사라진다.<br>재인증은 **카드사 단위**다. 설정 카드 영역의 카드사별 묶음 안에 둔다. |
| FN-SY-100 | 재인증 진입점은 카드사별 묶음 안. 공통 영역에는 '카드사 추가'만 남긴다. |
| FN-FR-080 | 공개 판정의 3회 · 단골 10회는 **최근 6개월 횟수**(K3). K1~K3 기본안을 기재한다. |
| FN-PL-051 | 내 장소 핀의 숫자(1~9)와 단골 표식(10+)은 **최근 6개월 횟수**. |
| FN-SE-020 | 미리보기 숫자는 최근 6개월 횟수로 판정한다.<br>숨기기 목록은 **방문한 모든 장소**를 대상으로 한다.<br>행마다 상태를 표시한다: '친구에게 보여요' / '아직 안 보여요 · 3번 가면 보여요'.<br>미리 숨긴 곳은 3번째 방문 뒤에도 보이지 않는다. |

| FN-RE-030 | 세부 조건 이름은 시간대 칩을 따라간다.<br>현재 시간대면 '지금 영업중'이고 기기 시각으로 판단한다.<br>다른 시간대면 'OO에 영업중'이고 그 시간대 대표 시각으로 판단한다. |
