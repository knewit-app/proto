# 기능명세서 v3.11.1 변경분

**친구 추가(S-MY-04) 위계 정리 · 카카오톡 초대 시트 추가.** 프로토타입은 `v/3.11.1.html`. 기준은 v3.11, 모양 기준은 레포 루트 `DESIGN.md`.

## 화면

### S-MY-04 친구 추가 — 순서 바꿈

| 순서 | 요소 | 내용 |
| --- | --- | --- |
| 1 | 아이디로 찾기 | 상단 바 바로 아래 iOS 검색칸. 자리 표시 글 ‘아이디로 찾기’. 입력이 있으면 오른쪽에 지우기(ⓧ). **입력하는 동안에는 결과만 보이고 2 · 3 · 4는 숨김.** 지우면 다시 보임. 1글자는 ‘2글자 이상 입력해 주세요.’, 결과 없음은 ‘‘…’로 찾은 사용자가 없어요.’ |
| 2 | 초대하기 | 설명 한 줄 ‘앱이 없는 친구도 링크로 가입하면 바로 친구가 돼요’ + 주 버튼 ‘카카오톡으로 초대’(카카오 노랑 캡슐, S-MY-04a를 엶) + 그 아래 텍스트 버튼 ‘링크 복사’(토스트 ‘초대 링크를 복사했어요’). 링크 주소는 화면에 쓰지 않음 |
| 3 | 보낸 요청 N | **보낸 요청이 있을 때만.** 그룹 목록 행: 아바타 · 이름 · @아이디 · ‘취소’. 취소하면 행이 사라지고 토스트 ‘요청을 취소했어요’. 마지막 행을 취소하면 섹션도 사라짐 |
| 4 | 내 아이디 | 맨 아래 한 줄 행 ‘내 아이디 @gyeore’ + 오른쪽 ‘복사’(토스트 ‘아이디를 복사했어요’) |

화면 노트: 위에서부터 아이디로 찾기 → 초대하기 → 보낸 요청 → 내 아이디. 진입점(프로필 → 친구 목록 → ＋, 홈 친구 세그먼트)과 ‘받은 요청은 확인할 일에 모은다’는 그대로.

삭제: 내 프로필 카드(이름 · @아이디), ‘친구는 @gyeore로 나를 찾을 수 있어요.’ 문장, 초대 링크 주소 상자, 큰 회색 ‘링크 복사하기’ 버튼, ‘미리보기’ 링크, 소제목 ‘초대 링크 보내기’ · ‘아이디로 추가’.

### S-MY-04a 카카오톡 초대 [BS] — 새 시트

| 요소 | 내용 |

| 미리보기 | ‘받는 사람에게 이렇게 보여요’ + OG 카드: 보내는 사람 아바타 · ‘{이름}님이 KNEWIT 친구로 초대했어요’ · 설명 문구 · 링크 도메인 `knewit.kr` · ‘KNEWIT에서 보기’ |

| 주 버튼 | ‘카카오톡으로 보내기’ → 시트 닫힘 + 토스트 ‘카카오톡 공유 화면을 엽니다’ |

## 기능명세서 행

| 행 ID | 바꿀 내용 |
| --- | --- |
| S-MY-04 (화면 행) | 구성 순서를 위 1~4로 다시 씀. 화면 노트의 순서 설명도 같은 순서로 고침 |
| FN-FR-010 | 아이디 검색은 친구 추가 화면의 **첫 요소**(상단 바 바로 아래)다. 입력하는 동안에는 검색 결과만 보이고 다른 섹션은 숨긴다. 입력을 지우면 원래 구성으로 돌아온다. 검색 · 결과 · 요청 · 요청 취소 동작은 그대로 |
| FN-FR-020 | 초대는 ‘카카오톡으로 초대’ → **카카오톡 초대 시트(S-MY-04a)**에서 받는 사람에게 보일 카드를 확인한 뒤 보낸다. 보조로 ‘링크 복사’. **링크 주소는 화면에 보여 주지 않는다**(카드에는 도메인만) |
| FN-FR-051 | 보낸 요청 취소는 S-MY-04 **‘보낸 요청’ 목록**의 ‘취소’에서 한다. 검색 결과의 ‘요청됨 ✕’로도 취소할 수 있다(유지). 취소 토스트는 ‘요청을 취소했어요’ |
| 시트 목록 | **S-MY-04a 카카오톡 초대 [BS]** 추가 (부모 S-MY-04, 관련 FN-FR-020) |
